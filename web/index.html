Health Checks + Sizing & Migration Assessments

Your VMware estate, explained.

Ask questions about your inventory. Get health checks, migration assessments and cloud sizing from the same RVTools workbook.

Inventory & consolidation

  • Answer questions about VMs, operating systems, power states, hosts, clusters, and hardware.
  • Calculate CPU and memory overcommit ratios.

Health & lifecycle

  • Run vSphere health checks, including host hardware and guest operating-system lifecycle and support status.

VCF readiness

  • Review VMware Cloud Foundation readiness.

Licensing & costs

  • Estimate required VCF cores and included, additional, or surplus vSAN capacity.
  • Create provider-priced bills of materials.

Migration & sizing

  • Compare HCX vMotion, Replication Assisted vMotion (RAV), Bulk Migration, and Cold Migration per VM.
  • Assess each workload for migration to OCVS, AVS, or GCVE using HCX vMotion, Replication Assisted vMotion (RAV), Bulk Migration, or Cold Migration.
  • Size cloud VMware clusters with repeatable CPU, memory, failure-capacity, storage, and full-silicon VCF calculations (as per updated core-counting guidance of June 17, 2026. Broadcom KB 313548).
  • Explore OCVS shapes, AVS hosts, and GCVE nodes through normal questions.

Reports

  • Create self-contained HTML and Markdown reports.

Usage examples

With your workbook available, invoke the installed skill or plugin in chat:

  • Codex skill
    $rvtools-analyzer How many virtual machines are powered off?
  • Claude Code plugin
    /rvtools:analyze What are the CPU and memory overcommit ratios for cluster Production?
  • ChatGPT Desktop plugin
    @RVTools Analyzer Desktop Run a vSphere health check and create an HTML report.
  • ChatGPT cloud plugin
    @RVTools Analyzer Assess this environment for an OCVS migration using HCX.
  • Codex skill
    $rvtools-analyzer Size this estate for OCVS with the recommended assumptions and retain the existing populated cluster structure.
  • Claude Code plugin
    /rvtools:analyze Create an OCVS sizing report with a provider-specific bill of materials in EUR.

These are chat prompts, not terminal commands. In ChatGPT, type @ and select RVTools Analyzer Desktop or RVTools Analyzer from the menu; the names above represent that selected mention.
